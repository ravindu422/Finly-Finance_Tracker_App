# 💰 Finly - Personal Finance Tracker
Finly is a modern **Android mobile application** built with **Kotlin (MVVM architecture)** and **XML-based UI**.  
It helps users manage **income, expenses, savings, budgets, and notifications**, with features for **statistics visualization**, **data persistence**, and a **user-friendly navigation experience**.

## ✨ Features

- 📌 **Transaction Management** – Add, edit, and delete income & expense records  
- 📊 **Statistics Dashboard** – View spending analysis with **Pie Charts** and **Line Charts**  
- 💸 **Budget Setup** – Set monthly budgets and track progress  
- 🔔 **Notifications** – In-app and background reminders for transactions  
  - Mark notifications as **Read/Unread**  
- 🌙 **Theme & Settings** – Toggle light/dark theme, choose currency, enable/disable reminders  
- 📂 **Data Backup & Restore** – Export or import personal finance data
